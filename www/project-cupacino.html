Cup-a-cino:
Webflow website & React Native app

Een CMS-gedreven e-commerce ervaring voor specialty koffiebonen. Webflow voor de shop en content, React Native voor mobiel gebruik met live API-data.

Context

Cup-a-cino is een fictief koffieconcept waar ik een consistente merkervaring wilde bouwen voor web en mobiel. De Webflow-site beheert producten en blogs via CMS. De React Native app leest diezelfde CMS-data via de Webflow API zodat content en producten centraal beheerd kunnen worden.

Uitdaging

Ontwerp en bouw een eenvoudige maar robuuste flow die zowel op een publieke Webflow-site als in een mobiele app werkt. Data moet dynamisch zijn en meteen updaten in de app wanneer de CMS-content verandert. De app moet producten tonen, filteren en laten bestellen in een demo-winkelmand.

Oplossing

Tweedelige aanpak: een Webflow-site met CMS-collecties voor Products en Blogposts, en een React Native app die de Webflow CMS API gebruikt. Features: dynamische productlists, productdetailpagina’s, blogposts, filter, zoek, sort, en een eenvoudige winkelmand in de app.

Mijn proces

Research & scope

  • Doelgroep bepalen: koffieliefhebbers die online bestellen
  • Competitie en referenties analyseren
  • Features prioriteren voor examenvereisten

Design

  • Wireframes in Figma voor homepage, productlist en productdetail
  • Design system: kleuren, typografie en spacing
  • Responsive layouts voor mobiel en desktop

Implementatie Webflow

  • Collections aanmaken en voorbeelditems toevoegen
  • Homepage met dynamic lists en collection bindings
  • Publish en test live content

Implementatie App

  • Expo + React Navigation opzetten
  • API-calls implementeren en UI koppelen
  • Cart state en AsyncStorage voor persistentie

Reflectie

Deze case study toont hoe design en development samenkomen. Ik leerde praktisch werken met Webflow CMS en hoe je die data veilig en efficiënt beschikbaar maakt voor een mobiele app. Voor examenvragen kan ik in detail uitleggen: de CMS-structuur, API-requests, component logica in React Native, en state management voor de cart.
